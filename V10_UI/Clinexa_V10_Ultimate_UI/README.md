# Clinexa V9

Start with **README_V9.md** for installation, features and verification. **COVERAGE_V9.md** records the status of every item in the upgrade request. Double-click **INSTALL_V9.bat** from the extracted folder to upgrade the existing Windows project.

The application is Flutter + FastAPI/SQLAlchemy, with local Ollama/Tesseract integration. New workflows cover clinical drafts/revisions, specimen tracking and verification, account security, patient sharing, threaded staff messaging, audit filtering and opt-in device reminder source.

Older README files are historical release notes. The V9 notes and coverage table are authoritative for this package.
